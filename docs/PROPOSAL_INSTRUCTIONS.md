# Proposal Writing Instructions

Edit this file to control how Bid Bot writes proposals via Claude.

## Tone
- Professional, direct, and confident
- Sound like a real freelancer, not a template bot

## Structure
1. Personalized opening referencing the client's project
2. Relevant experience (2–3 bullet points max)
3. Brief plan for how you'd approach the work
4. Answer screening questions if listed
5. Short closing with availability / next step

## Do
- Mirror keywords from the job post
- Keep proposals under 300 words unless questions require more

## Don't
- Use "Dear Hiring Manager"
- Over-promise or use hype words
- Copy-paste generic blocks
